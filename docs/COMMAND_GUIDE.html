PlanX Suitability Lab - Detailed Command Guide (EN/TR)

EN: This guide explains each production-ready command and practical tips for reliable MCDA results.

TR: Bu rehber paylasima hazir komutlari ve guvenilir MCDA sonucu icin pratik ipuclarini aciklar.

1) Prepare / Hazirlik

data_harmonizer: Align CRS, extent, resolution, nodata and export full aligned raster stack folder + manifest.

synthetic_sample_raster: Generate 4 criterion rasters + hard mask for smoke testing.

synthetic_pipeline_runner: One-click synthetic end-to-end workflow execution.

Tip: Start with the most trusted base raster as SNAP_RASTER.

2) Criteria / Kriterler

vector_rasterizer, proximity_builder, normalizer_reclassifier, constraint_builder

Normalizer modes: Min-Max (benefit/cost), Fuzzy Linear (benefit/cost), Fuzzy Sigmoid (benefit/cost), Fuzzy Gaussian.

Tip: Keep all criterion scores in 0-100 before weighted overlay.

3) Weights / Agirliklar

ahp_weights: pairwise matrix + consistency ratio.

pca_derived_weights: variance-driven weights.

entropy_weights: information-content driven weights.

critic_weights: objective weights from contrast intensity and inter-criterion conflict.

weight_consolidator: pick active scenario weights.

scenario_weight_pack: merge AHP/PCA/Entropy/CRITIC tables and add blended average scenario.

weight_consensus_audit: method-agreement diagnostics (mean, range, CV%, HIGH/MEDIUM/LOW agreement).

4) Compose / Bilesim

wlc_suitability: bounded [0,100] weighted linear combination + hard mask.

owa_suitability: true OWA with criteria weights + order weights + ordering mode + optional hard mask.

topsis_suitability: TOPSIS ranking in raster space with benefit/cost impacts + optional hard mask.

vikor_suitability: VIKOR compromise ranking (group utility + individual regret) with optional hard mask.

ensemble_suitability: multi-scenario synthesis (ensemble_mean/std/p10/p90/confidence).

scenario_consensus_zone: computes per-cell scenario agreement and outputs consensus count + consensus zone classes.

scenario_disagreement_attention: maps cross-scenario conflict score and attention classes for contested high-value areas.

decision_quadrant_map: classifies cells by suitability (high/low) and disagreement (high/low) to support execution strategy zoning.

intervention_conflict_matrix: combines priority and conflict into actionable classes (quick-win, resolve-first, co-design, re-screen).

risk_opportunity_matrix_map: combines robust suitability and uncertainty into invest-now / validate-then-invest / defer strategy classes.

regret_fragility_map: computes scenario-spread regret fragility score and classes (stable/watch/fragile) for contested-zone detection.

opportunity_loss_map: maps suitability forfeited by hard constraints, with loss class (0=None, 1=Low, 2=Medium, 3=High).

priority_zoning_from_suitability: action zoning from suitability, confidence and opportunity-loss (0 low, 1 longlist, 2 feasibility, 3 immediate, 4 constraint revisit).

candidate_site_extractor: extracts ranked candidate site polygons (site_id, rank, area_ha, mean/max suitability, compactness) from contiguous high-suitability patches with threshold, minimum-area and top-N controls.

uncertainty_adjusted_suitability: robust score from unc_mean - lambda * unc_std (clipped to 0-100).

scenario_comparator: delta map across two suitability scenarios.

5) Uncertainty + Explainability

montecarlo_suitability: unc_mean, unc_std, unc_p05, unc_p50, unc_p95, stability_index.

xai_global_sensitivity, xai_local_contribution, xai_geoshapley_lite.

numerical_qa_check: checks suitability bounds and percentile consistency.

scenario_markdown_brief: planning memo style markdown output with QA and recommendation template.

suitability_class_area_stats: class-based area share table (coverage and percent by score band).

scenario_similarity_matrix: pairwise scenario agreement table with Pearson r, MAE and RMSE.

scenario_dominance_matrix: pairwise win/loss/tie matrix with net-dominance rank to show which scenario most often outperforms others cell-by-cell.

method_benchmark_leaderboard: ranks scenario rasters by composite MCDA execution score (mean, p90, high-coverage and stability).

scenario_robustness_leaderboard: fuses benchmark, dominance, minimax-regret and diversity evidence into a single robustness rank and tier.

scenario_portfolio_diversity: portfolio redundancy/diversification audit with diversity index, effective method depth and scenario uniqueness roles.

minimax_regret_selector: identifies the scenario with minimum worst-case regret (Savage criterion) and reports rank diagnostics.

scenario_governance_audit: flags governance risk per scenario (regret, robustness, volatility) and emits portfolio-level governance status.

alignment_audit: validates criterion raster alignment against a snap/reference raster (pixel size, extent, dimensions).

policy_sensitivity_frontier: lambda-sweep frontier table (mean/median/p90 and area shares above 60/80).

criterion_redundancy_diagnostics: criterion overlap diagnostics with pairwise correlations, per-criterion max/mean abs correlation and VIF flags.

constraint_impact_audit: quantifies suitability loss and high-suitability exclusion by each hard-constraint mask and total union.

priority_transition_matrix: baseline vs scenario priority-zone transition table with transition classes (upgrade/stable/downgrade).

spatial_fragmentation_audit: patch-count and compactness diagnostics for high-suitability spatial structure.

consensus_zone_area_stats: area distribution table for consensus zone classes (low to near-unanimous).

attention_class_area_stats: area distribution table for disagreement attention classes (watch/review/high/critical).

threshold_coverage_curve: threshold sweep table (area and percent above each suitability cutoff) for policy tuning.

executive_kpi_snapshot: one-row management dashboard metrics across suitability, robustness, eligibility, consensus and conflict.

policy_gate_recommender: proposes threshold and lambda gates from threshold-coverage and frontier tables.

decision_quadrant_area_stats: area distribution table across decision quadrants (quick-win vs contested vs low-priority buckets).

intervention_conflict_area_stats: area distribution table for intervention conflict classes.

risk_opportunity_area_stats: area distribution table for robust/uncertainty strategy classes.

regret_fragility_area_stats: area distribution table for regret fragility classes (stable/watch/fragile).

actionability_scorecard: computes an overall readiness score (A-D) using KPI, budget capture and policy-gate diagnostics.

scenario_selection_recommender: proposes primary and challenger scenarios by combining benchmark, robustness, minimax-regret, portfolio diversity and policy-readiness context.

implementation_wave_planner: builds a four-wave execution plan from priority zoning and risk-opportunity classes.

deployment_readiness_gate: produces an automated GO/CONDITIONAL/HOLD publication gate from scorecard, minimax, wave and fragility diagnostics.

intervention_budget_phasing: budget-step capture curve from priority zones and index (cells, cumulative impact, capture %).

action_playbook_generator: creates a structured markdown implementation playbook from priority zones, frontier, and scenario similarity diagnostics.

release_narrative_builder: auto-generates EN/TR one-paragraph release narrative from frontier, budget and similarity evidence.

beta_evidence_report: outputs registry-level release readiness HTML evidence; optionally verifies key artifact files from a synthetic/real run output directory.
