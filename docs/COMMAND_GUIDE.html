PlanX Suitability Lab - Detailed Command Guide (EN/TR)

EN: This guide explains each production-ready command and practical tips for reliable MCDA results.

TR: Bu rehber paylasima hazir komutlari ve guvenilir MCDA sonucu icin pratik ipuclarini aciklar.

1) Prepare / Hazirlik

data_harmonizer: Align CRS, extent, resolution, nodata and export full aligned raster stack folder + manifest.

synthetic_sample_raster: Generate 4 criterion rasters + hard mask for smoke testing.

synthetic_pipeline_runner: One-click synthetic end-to-end workflow execution.

Tip: Start with the most trusted base raster as SNAP_RASTER.

2) Criteria / Kriterler

vector_rasterizer, proximity_builder, normalizer_reclassifier, constraint_builder

Normalizer modes: Min-Max (benefit/cost), Fuzzy Linear (benefit/cost), Fuzzy Sigmoid (benefit/cost), Fuzzy Gaussian.

Tip: Keep all criterion scores in 0-100 before weighted overlay.

3) Weights / Agirliklar

ahp_weights: pairwise matrix + consistency ratio.

pca_derived_weights: variance-driven weights.

entropy_weights: information-content driven weights.

weight_consolidator: pick active scenario weights.

scenario_weight_pack: merge AHP/PCA/Entropy tables and add blended average scenario.

4) Compose / Bilesim

wlc_suitability: bounded [0,100] weighted linear combination + hard mask.

owa_suitability: true OWA with criteria weights + order weights + ordering mode + optional hard mask.

topsis_suitability: TOPSIS ranking in raster space with benefit/cost impacts + optional hard mask.

uncertainty_adjusted_suitability: robust score from unc_mean - lambda * unc_std (clipped to 0-100).

scenario_comparator: delta map across two suitability scenarios.

5) Uncertainty + Explainability

montecarlo_suitability: unc_mean, unc_std, unc_p05, unc_p50, unc_p95, stability_index.

xai_global_sensitivity, xai_local_contribution, xai_geoshapley_lite.

numerical_qa_check: checks suitability bounds and percentile consistency.

scenario_markdown_brief: planning memo style markdown output with QA and recommendation template.

suitability_class_area_stats: class-based area share table (coverage and percent by score band).

beta_evidence_report: outputs registry-level release readiness HTML evidence.
